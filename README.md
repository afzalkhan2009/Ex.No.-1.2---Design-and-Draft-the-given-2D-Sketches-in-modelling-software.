1. AIM
To create a two-dimensional (2D) sketch of the given engineering drawing with accurate dimensions using
Autodesk Fusion 360 software and prepare the drawing in the standard ISO format.

2. SOFTWARE AND SYSTEM REQUIREMENTS

Software Required: Autodesk Fusion 360. Hardware and System Requirements:  Operating System: Windows 10 or above.  RAM: 16 GB recommended.  Graphics: Integrated graphics with 1 GB or more graphics memory recommended.  Internet Connection: 2.5 Mbps or faster download speed.  Upload Speed: 500 Kbps or faster.


3. INTRODUCTION

Autodesk Fusion 360 is a computer-aided design (CAD), computer-aided manufacturing (CAM), and computer- aided engineering (CAE) software used for designing and modelling engineering components. It provides tools
for creating 2D sketches, developing 3D models, modifying geometry, checking dimensions, and preparing
technical drawings. In this experiment, the given engineering profile is created using sketching and modifying tools in Fusion 360. The completed model is then used to prepare a dimensioned technical drawing according to the ISO standard.

4. TOOLS USED

 Line Tool: Used to draw straight lines between selected points.
 Circle Tool: Used to create circles by specifying their centre and size.
 Arc Tool: Used to draw curved portions of the sketch.
 Rectangle Tool: Used to create rectangular profiles.
 Polygon Tool: Used to create regular polygonal shapes.
 Trim Tool: Used to remove unwanted portions of sketch geometry.
 Mirror Tool: Used to create symmetrical copies of selected geometry.
 Move/Copy Tool: Used to reposition or duplicate sketch elements.
 Dimension Tool: Used to assign dimensions and control the size of sketch elements.
 Inspect Tool: Used to measure and verify distances and other dimensions.


5. PROCEDURE

Step 1: Open Autodesk Fusion 360
Open Autodesk Fusion 360 on the computer. Sign in to the Autodesk account if required and create a new
design using the New Design option. 

Step 2: Create a New Sketch
Click Create Sketch from the toolbar. The available reference planes (XY, YZ and XZ) will be displayed. Select
the suitable plane according to the orientation of the given drawing. 

Step 3: Draw the Basic Geometry
In the sketch environment, choose the required tools such as Line, Circle, Arc, Rectangle and Polygon. Draw the
main outline and internal features by following the given engineering drawing. 

Step 4: Modify the Sketch
Use the sketch modification tools to correct and refine the geometry. The Trim tool removes unwanted or
overlapping portions, Mirror creates symmetrical features, and Move/Copy repositions or duplicates selected
elements. Apply other required editing tools to complete the profile. 

Step 5: Apply Dimensions
Select the Dimension tool and click the required lines, circles, arcs or other geometric elements. Enter the
dimensions specified in the given drawing. Check that the geometry follows the required measurements.

Step 6: Inspect the Sketch
Select the Inspect option from the toolbar to measure and verify important dimensions. Check distances, diameters, radii and other measurements against the given drawing. 

Step 7: Finish the Sketch and Create the Model
After completing and checking the sketch, click Finish Sketch. If the exercise requires a solid component, use
the appropriate modelling command, such as Extrude, and specify the required thickness. This produces the 3D
component shown below. Figure 1: Completed 3D model in Autodesk Fusion 360
